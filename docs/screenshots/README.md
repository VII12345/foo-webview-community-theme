# README 截图清单

截图统一放在本目录，文件名照下表。拍好后把原图（PNG，建议 1920 × 1080 或 2560 × 1440，
单张不超过 2 MB）发来即可；README 里的占位表会替换成图片。

## 拍摄约定

- 窗口 1920 × 1080 左右，Windows 缩放 100%；浅色主题；选一首封面颜色鲜明、带逐字歌词的歌。
- 除非特别说明，保留完整窗口（含标题栏与底部播放栏），不要裁掉侧边栏。
- 沉浸视图按 F11 全屏后截图；图纸/聚焦/歌词/卡片/卡片歌词各一张。
- 不要出现私人路径、用户名、其他窗口；需要打码的地方提前处理。

## 插入方式

图片到位后，README 的“截图”表格会换成：

```html
<p align="center">
  <img src="docs/screenshots/01-home.png" alt="首页" width="49%" />
  <img src="docs/screenshots/02-now-playing.png" alt="播放页" width="49%" />
</p>
```

沉浸视图的五张可以做成 2 × 3 的网格。发行说明里也会同步引用核心 8 张。
